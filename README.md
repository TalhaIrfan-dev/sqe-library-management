# SQE Library Management

## Project Description

The **SQE Library Management System** is a software project developed as part of the **Software Quality Engineering (SQE)** course. The project focuses on applying software engineering and software quality practices using a GitHub-based development workflow.

The system is designed to manage basic library operations, including **book management, member management, and book searching**.

## Main Features

* **Book Management** — Add, update, delete, and view book information.
* **Member Management** — Add, update, delete, and view member information.
* **Book Search** — Search for books and check their availability.

## GitHub Project Management

GitHub is used for version control and project management. The project includes GitHub Issues for tracking tasks, labels for categorizing issues, and a GitHub Project board for monitoring task progress.

## Project Objective

The objective of this project is to practice software quality activities within a professional GitHub-based development workflow, including version control, issue tracking, testing, documentation, and project management.
